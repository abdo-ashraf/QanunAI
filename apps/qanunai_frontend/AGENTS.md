# AGENTS.md (Frontend)

## Stack
- React + Vite + TypeScript
- TanStack Query for server-state
- Zod for runtime data validation
- shadcn/ui component conventions
- ai-elements CLI for AI-focused UI primitives

## Architecture
- Follow feature-based organization under `src/features/*`.
- Keep UI primitives under `src/components/ui`.
- Keep shared helpers under `src/lib`.

## Commands
- Install: `npm install`
- Dev: `npm run dev`
- Lint: `npm run lint`
- Build: `npm run build`
- AI Elements CLI: `npm run ai:elements`
